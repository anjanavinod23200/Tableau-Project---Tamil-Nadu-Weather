TABLEAU DATA ANALYSIS PROJECT


TITLE : Tamil Nadu Weather Analysis

DATASET DESCRIPTION :

        This project analyses weather data from Tamil Nadu using Tableau. The dataset contains weather-related information across different cities and time periods.
It includes key fields such as Temperature, Relative Humidity, Dew Point, Precipitation, Rainfall, Surface Pressure, Cloud Cover, Wind Speed, Wind Direction, Date, Time, City and Rain Tomorrow.
The dataset is used to explore weather patterns, analyse climatic conditions, compare weather indicators and examine rainfall trends and future rain predictions.


BUSINESS QUESTIONS :

1.	What is the average temperature across different cities?
2.	How does temperature vary over different months?
3.	What are the trends in monthly rainfall and precipitation?
4.	How does humidity vary over time?
5.	What is the cloud cover distribution across different cities?
6.	How does wind speed vary among cities?
7.	What is the predicted rain status for the following day?
8.	How do different weather conditions vary across Tamil Nadu?
